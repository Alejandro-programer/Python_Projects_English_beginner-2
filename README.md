# 🚀 Run a Project

Clone the repository:

```bash
git clone https://github.com/Alejandro-programer/Python_Projects_English_beginner.git
```

Enter the folder:

```bash
cd Python_Projects_English_beginner
```

Run any challenge:

```bash
python challenge_name.py
```

Example:

```bash
python "Guessing Game.py"
```
