## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/python-projects-world2.git
```

2. Enter the project directory:

```bash
cd python-projects-world2
```

3. Run any Python file:

```bash
python "Guessing Game.py"
```

or

```bash
python "Prime Numbers.py"
```
